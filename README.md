The second book in *The Curious Coder* series. It takes you from writing single statements to building complete Python programs, and ends with a full capstone project.

## What this book is

Part I taught you how a program thinks. Part II teaches you how to build things that last longer than ten lines: programs that repeat work, organize data, reuse their own logic, survive bad input, and save their results to disk.

The same approach continues from Part I: runnable examples, hands-on exercises, a full answer key, and Minecraft/PvP themed examples (inventories, players, tournaments) that are easy to picture.

## What's inside (Chapters 11–23)

11. **Loops and Repetition** — repeating work with loops instead of repeating code.
12. **Controlling Loops and Solving Repetitive Problems** — `break`, `continue`, loop `else`, and loop-based problem solving.
13. **Lists and Working with Sequences** — storing, changing, and looping over ordered data, including `enumerate()`.
14. **Processing Collections of Data** — working through whole collections, including `zip()`.
15. **Tuples and Sets** — fixed groups of values and collections of unique items.
16. **Dictionaries and Key-Value Data** — looking up data by name instead of by position.
17. **Functions and Reusable Logic** — defining functions, parameters, and return values.
18. **Function Design and Variable Scope** — designing clear functions, the LEGB scope rules, lambda expressions, and avoiding mutable default arguments.
19. **Exceptions, Debugging, and Input Validation** — `try`/`except`/`finally`, debugging, validating input, and a first look at `assert`.
20. **Files and Persistent Data** — reading and writing files with `with open()`, `pathlib`, and JSON.
21. **Modules, Imports, and Organizing Projects** — splitting code into modules, `__name__`, and virtual environments.
22. **Comprehensions and Concise Data Processing** — building and transforming collections in one readable line.
23. **Capstone: Build a Task Management Application** — a complete program that adds, edits, searches, and filters tasks, saves them to JSON, and validates the data it loads.

## Who it's for

- Readers who finished **Part I**, or who already know variables, input and output, operators, strings, conditions, and Boolean logic.
- Beginners who want to move from short exercises to real, finished programs.

If you're brand new to programming, start with Part I.
